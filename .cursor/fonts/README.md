# فونت‌های نسک فارسی — استفادهٔ داخلی

این پوشه برای گرافیک (اینستاگرام، صفحهٔ کتاب، پوستر) است، نه برای سایت زنده.  
`_config.yml` مسیر `.cursor` را از بیلد جکیل کنار می‌گذارد؛ این فایل‌ها در `_site/` منتشر نمی‌شوند.

همه با **SIL Open Font License 1.1** هستند. متن مجوز کنار هر خانواده است.

## کدام فونت برای چه

| فایل | خانواده | کاربرد |
|------|---------|--------|
| `XB-Zar-Bold.ttf` / `XB-Zar.ttf` | زر (X Series 2) | نزدیک‌ترین نسک چاپی کتاب‌های افست دههٔ ۶۰. عنوان **ماجراهای کوه** با زر بولد چیده شد. |
| `XB-Niloofar-Bold.ttf` / `XB-Niloofar.ttf` | نیلوفر ≈ لوتوس | نسک رایج کتاب فارسی همان دوره |
| `XB-Titre.ttf` | تیتر | تیتر درشت روزنامه/جلد، نه متن کتاب |
| `Amiri-Bold.ttf` / `Amiri-Regular.ttf` | امیری | نسک کلاسیک عربی/فارسی |
| `ScheherazadeNew-Bold.ttf` | Scheherazade New (SIL) | نسک سنتی |
| `Gandom.ttf` | گندم | نسک جدیدتر، برای متن کتاب قدیمی مناسب نیست |

برای عنوان چاپی کتاب‌های افست ۱۳۶۰–۱۳۷۰: اول **زر بولد**، بعد نیلوفر بولد. نستعلیق نه.

## مجوزها

- `OFL-XB.txt` — نیلوفر، تیتر، زر (IRMUG X Series 2)
- `OFL-Amiri.txt` — امیری
- `OFL-Scheherazade.txt` — Scheherazade New
- `LICENSE-Gandom.txt` — گندم
